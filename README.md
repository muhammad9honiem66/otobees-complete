# 🚌 أتوبيس كومبليت

فكرة وتصميم وتطوير: **محمد غنيم** (Muhammad Ghoniem)

لعبة أتوبيس كومبليت أونلاين على ورقة بجدول مرسوم بالقلم الجاف (حرف، بنت، ولد، حيوان، جماد، نبات، بلاد، المجموع). الغرفة بتاخد لحد ٢٠ لعّيب.

## طريقة اللعب
1. **إنشاء غرفة:** تكتب اسمك وتاخد رقم غرفة من ٦ حروف وأرقام (زي `K7P2QX`) تبعته لأي حد. **الانضمام لغرفة:** يكتب اسمه والرقم.
2. اختيار الحرف بيلف بالترتيب: أول واحد دخل الغرفة يختار الأول، وبعده اللي بعده. الحروف كلها قدامه، واللي اتلعب قبل كده بيبقى متظلل ومش متاح.
3. الكل يشوف "محمد اختار حرف الـ ب"، وبعدها عد تنازلي من ٥ وتبدأ الكتابة.
4. اللي يخلص يدوس **خلصت**، فالجولة تقف عند الكل ويظهر "محمد خلّص".
5. **الحساب:** كل الإجابات بتظهر، وكل واحد يختار لنفسه تحت كل كلمة ٥ أو ١٠، والمجموع بيتحسب لوحده. اللعبة بتحط اقتراح مبدئي (المتكررة ٥، والفاضية أو اللي مش بالحرف صفر)، وانتو تعدّلوا براحتكم.
6. لما الكل يدوس **تمام**، يظهر ترتيب الجولة والمجموع الكلي، وبعدها جولة جديدة.
7. **الجيم بيخلص** لما تدوسوا "إنهاء الجيم وعرض النتيجة النهائية"، أو لما الـ ٢٨ حرف يخلصوا.

## التشغيل (حوالي ٢٠ دقيقة، مرة واحدة بس)

### ١) Firebase (المزامنة بين السعودية ومصر، مجاني)
1. ادخل https://console.firebase.google.com ← **Add project** ← اسم `otobees-complete` (اقفل Google Analytics).
2. **Build ← Realtime Database ← Create Database** ← اختار **Belgium (europe-west1)** (أقرب لمصر والسعودية) ← **Start in locked mode**.
3. تاب **Rules**: امسح الموجود والصق محتوى ملف `database.rules.json` ← **Publish**.
   - **Authentication ← Sign-in method ← Anonymous ← Enable** (كل جهاز بياخد هوية سرية من غير تسجيل).
4. ⚙️ **Project settings ← Your apps ← أيقونة Web `</>`** ← سجّل التطبيق ← انسخ `firebaseConfig`.
5. افتح `firebase-config.js` وحط الـ config مكان `null` (اتأكد إن فيه `databaseURL`).

### ٢) الرفع على GitHub Pages (من حسابك muhammad9honiem66)
1. github.com ← **New repository** ← اسم `otobees-complete` ← Public ← Create.
2. **Add file ← Upload files** ← ارفع كل الملفات اللي في الفولدر ده ← Commit.
3. **Settings ← Pages ← Branch: main / root ← Save**.
4. بعد دقيقة اللعبة هتبقى على: `https://muhammad9honiem66.github.io/otobees-complete/`

### ٣) التطبيق على الموبايل
- **الأسرع:** افتح اللينك من Chrome على الموبايل ← ⋮ ← **Add to Home screen / تثبيت التطبيق**. هتتنزل بأيقونة واسم "أتوبيس كومبليت" وتفتح زي أي تطبيق.
- **ملف APK حقيقي:** ادخل https://www.pwabuilder.com ← حط اللينك ← **Package for stores ← Android ← Download**. هتاخد ملف `.apk` تبعته لمراتك على واتساب وتنزّله.

## ملاحظات
- لو `firebase-config.js` فاضي، اللعبة بتشتغل "وضع تجربة" على نفس الجهاز بس (افتحها في تابتين).
- لو قفلت التطبيق ورجعت، بيرجعك لنفس الروم أوتوماتيك.
- لو صاحب الروم خرج، أقدم لعّيب موجود بياخد مكانه.
## الأمان
- اللعبة مش بتطلب أي صلاحية من الموبايل (لا كاميرا ولا مايك ولا صور ولا جهات اتصال ولا موقع).
- كل جهاز بياخد هوية سرية (Anonymous Auth)، والقواعد (`database.rules.json`) بتضمن إن كل لاعب ما يعدّلش غير اسمه وإجاباته ونقطه هو بس، ومحدش يقدر يمسح الغرفة أو يصفّر الجيم غير صاحبها.
- مفيش حد يقدر يشوف قايمة الغرف، ورقم الغرفة ٦ حروف وأرقام (أكتر من ملياري احتمال) فتخمينه مستحيل عملياً.
- الأسماء والإجابات بتتعرض كنص بس، فمحدش يقدر يحقن كود.
- خطة Firebase المجانية (Spark) من غير كارت بنك، يعني مستحيل تيجي فواتير.
- الخطة المجانية في Firebase بتستحمل ١٠٠ اتصال في نفس الوقت، يعني ٥ رومات مليانة مع بعض.
